# Security policy

## Report a vulnerability

Use GitHub's private vulnerability reporting: open the Security tab of this repository and choose "Report a
vulnerability". Do not open a public issue for a security problem.

If you cannot use that form, write to 347869794+sea4friends@users.noreply.github.com.

Say which version you use (`chart-grabber-cli --version`), what you did, and what happened. We answer as soon as we
can; this is a small project, so there is no fixed time.

## Supported versions

Only the latest release gets fixes. Update to the latest release before you report, if you can.

## Downloads from third-party servers

`chart-grabber-cli` downloads tiles from map servers that this project does not run. The terms of use of those
servers apply, and some forbid bulk download. You must read and respect them. A map server that sends wrong or hostile
data is outside this policy, but a way to make the program crash or write outside its output folder because of such
data is a vulnerability: please report it.
